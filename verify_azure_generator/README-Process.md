# Process Old Generator Services

This PowerShell script processes all services from the `old-generator-services.json` file to migrate them from the old TypeSpec generator to the new Azure generator.

## Files

- `Process-OldGeneratorServices.ps1` - Main processing script
- `old-generator-services.json` - Input file with services to process (generated by `Extract-OldGeneratorServices.ps1`)
- `Service-Migration-Helpers.ps1` - Helper functions for each migration step (TBD implementations)

## Usage

### Basic Usage
```powershell
# Process all services with dry run first
.\Process-OldGeneratorServices.ps1 -DryRun

# Process all services for real
.\Process-OldGeneratorServices.ps1
```

### Advanced Usage
```powershell
# Process specific services only
.\Process-OldGeneratorServices.ps1 -ServiceFilter "communication*" -DryRun

# Skip certain steps (useful for debugging)
.\Process-OldGeneratorServices.ps1 -SkipSteps @(7,8) -ServiceFilter "anomalydetector"

# Different log levels
.\Process-OldGeneratorServices.ps1 -LogLevel Verbose -DryRun
.\Process-OldGeneratorServices.ps1 -LogLevel Warning  # Only warnings and errors
```

### Parameters

- **ServicesJsonFile**: Path to the services JSON file (default: `old-generator-services.json`)
- **RepoRoot**: Repository root path (default: `D:\work\sdk2`)
- **LogLevel**: Logging level - `Verbose`, `Info`, `Warning`, `Error` (default: `Info`)
- **DryRun**: Show what would be done without executing (useful for testing)
- **ServiceFilter**: Filter to specific services using wildcards (e.g., `"communication*"`)
- **SkipSteps**: Array of step numbers to skip (1-9)

## Processing Steps

The script performs these steps for each service:

1. **Find relative path and convert to absolute path** - Converts SDK relative paths to absolute paths
2. **Navigate to service directory** - Changes to the service directory
3. **Update tsp-location.yaml** - ✅ Updates TypeSpec location configuration
4. **Update .csproj file** - *(TBD)* Updates project file for new generator
5. **Checkout spec** - *(TBD)* Checks out the appropriate spec version
6. **Update tspconfig.yaml** - *(TBD)* Updates TypeSpec configuration for new generator
7. **Generate code** - *(TBD)* Runs code generation with new generator
8. **Build code** - *(TBD)* Builds the generated code
9. **Generate report** - *(TBD)* Creates migration report

## Output

The script generates:
- **Log file**: `process-old-generator-services-YYYYMMDD-HHMMSS.log`
- **Results file**: `processing-results-YYYYMMDD-HHMMSS.json`

The results file contains:
- Summary statistics
- List of successfully processed services
- List of failed services with error details
